# 文件共享通信延迟测试

一个简单的 Node.js 测试程序，用于测量通过文件共享方式进行进程间通信 (IPC) 的延迟。

## 测试原理

```
┌─────────┐                    ┌─────────┐
│ Writer  │ ──── 写入 ────────> │ 文件系统 │
│ 进程    │ <───── 读取 ────────│ (共享)  │
└─────────┘                    └─────────┘
     │                               │
     │ ──── 写入 ─────────────────>  │
     │ <──── 读取 ────────────────── │
     │                               │
┌─────────┐                    ┌─────────┐
│ Reader  │ ──── 读取 ────────> │ 文件系统 │
│ 进程    │ <───── 写入 ────────│ (共享)  │
└─────────┘                    └─────────┘
```

1. **Writer** 将消息写入共享文件
2. **Reader** 轮询读取文件，检测新消息
3. **Reader** 处理消息后写入响应文件
4. **Writer** 读取响应并计算往返延迟

## 使用方法

```bash
# 安装依赖 (无需额外依赖，使用 Node.js 内置模块)
# 直接运行测试
npm test
# 或
node index.js
```

## 测试变量

可以在 `index.js` 中修改 `CONFIG` 对象来调整测试参数：

```javascript
const CONFIG = {
  messageCount: 100,    // 测试消息数量
  pollInterval: 1,      // 轮询间隔 (ms)
};
```

## 技术要点

- 使用 **轮询** 方式检测文件变化
- 使用 **JSON** 格式序列化消息
- 使用 **追加写入** 方式传递消息
- 测量的是 **往返延迟 (RTT)**

## 局限性

1. 轮询会消耗 CPU 资源
2. 延迟受文件系统性能影响
3. 不适合高频率通信场景
4. Windows 文件系统可能有额外锁定开销

## 适用场景

- 跨语言进程通信
- 无网络环境的数据交换
- 简单的队列实现
- 调试和测试用途
